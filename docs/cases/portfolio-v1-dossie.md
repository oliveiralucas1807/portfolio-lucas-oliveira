# Dossiê: Portfólio Light V1

## Cenário

Lucas precisava de um endereço público para apresentar trabalhos e currículo sem depender do tempo necessário para reorganizar o Behance. A urgência favorecia uma solução publicável, fácil de compartilhar e possível de atualizar com apoio do Codex.

## Problema

- acervo distribuído em várias pastas e clientes;
- pouco tempo para curadoria e construção manual;
- necessidade de imagem profissional, currículo e contato no mesmo fluxo;
- duas ambições concorrentes: publicar rápido e construir uma experiência mais refinada.

## Decisão central

A proposta mais extensa foi reduzida para um Portfólio Light. HTML, CSS e JavaScript estáticos permitiram uma entrega rápida no GitHub Pages. A versão mais ambiciosa permaneceu como direção futura.

## Processo documentado

- inventário de 2.635 arquivos nas fontes da Coimbra e 1.535 imagens candidatas;
- curadoria inicial e otimização de 48 imagens;
- estrutura modular de dados para site, cases e galeria;
- publicação em 13/06/2026;
- sete commits de refinamento em 15/06/2026;
- galeria 3:4 com visualização completa em lightbox;
- currículo e contato em modais;
- validação pública com seis cases, cerca de 120 imagens e console sem erros.

## Problemas e soluções

- Caminhos divergentes entre `public/assets` e `/assets`: corrigidos na prévia.
- Fonte caindo em Times New Roman: removida dependência de variável inexistente.
- Navegador bloqueando `file:///`: adotado servidor local.
- Ferramentas ausentes do PATH: validação estática e caminhos explícitos para Git e GitHub CLI.
- Propagação do Pages: verificação repetida de HTML, assets e status antes de refazer mudanças.
