# Referências visuais e técnicas

Pesquisa consolidada em 2026-07-26. As referências servem para decompor
soluções; não autorizam copiar identidade, textos ou imagens de demonstração.

## Referências principais

### Maria

- Repositório: https://github.com/xocothemes/maria
- Demo: https://maria-lake.vercel.app/
- Licença: MIT
- Usar como referência para: apresentação dos projetos, Work, About, imagens
  grandes e consumo rápido do case.
- Não herdar: posicionamento UX/UI/Product, textos, projetos demonstrativos,
  cookie banner sem necessidade ou dark mode como prioridade.

### Fuwari

- Repositório: https://github.com/saicaca/fuwari
- Demo: https://fuwari.vercel.app/
- Licença: MIT
- Usar como referência para: atmosfera clara, modularidade, conforto visual,
  hero ilustrado, cores e organização.
- Não herdar: estrutura de blog como página principal, Svelte ou recursos
  editoriais que não servem ao Light.

### Monolume

- Repositório: https://github.com/heshify/monolume
- Demo: https://monolume.vercel.app/
- Licença: MIT
- Usar como referência para: grid pontilhado, escala tipográfica e faixa de
  movimento.
- Não herdar: cursor customizado ou página de projeto superficial.

### Gothsec Astro Portfolio

- Repositório: https://github.com/Gothsec/Astro-portfolio
- Demo: https://oscarhernandez.vercel.app/
- Licença: MIT
- Usar como referência para: topbar translúcida, apresentação inicial,
  microinterações e detalhe musical.
- Não herdar: posicionamento de desenvolvedor, LetterGlitch, React sem
  necessidade ou integração externa antes de validar valor.

### DevPortfolio

- Repositório: https://github.com/RyanFitzgerald/devportfolio
- Demo: https://ryanfitzgerald.github.io/devportfolio/
- Licença: MIT
- Usar como referência para: texto grande, leitura clara, landing page,

- Não herdar: semântica de currículo de desenvolvedor ou projetos sem
  aprofundamento visual.

## Ferramentas

### Astro

- https://astro.build/
- Função: estrutura, páginas, componentes, conteúdo e build estático.
- Compatível com GitHub Pages.

### Tailwind CSS

- https://tailwindcss.com/
- Função: utilitários para responsividade, grid, cores, blur, transições e
  animações.
- Framework principal: gratuito e open source.
- Tailwind Plus é pago e não é necessário para a V2.

### Framer

- https://www.framer.com/
- Papel no estudo: prototipação visual e aprendizado de interações.
- Não é biblioteca para Astro; é plataforma alternativa com hospedagem própria.
- Plano gratuito usa domínio Framer; domínio personalizado exige plano pago.

### Webflow

- https://webflow.com/
- Papel no estudo: aprender construção visual, CMS e interações.
- Não é dependência recomendada para a V2.
- Plano gratuito é limitado; domínio próprio e recursos profissionais exigem
  plano pago.

### Resend

- https://resend.com/
- Função: envio de e-mails por API.
- Não cria efeitos visuais ou 3D.
- GitHub Pages não pode guardar a chave com segurança.
- Avaliar apenas se houver formulário, newsletter ou notificações.

## Regra de extração futura

Para cada referência escolhida:

1. identificar o componente exato;
2. verificar licença;
3. entender como funciona;
4. reimplementar com identidade própria;
5. testar acessibilidade e desempenho;
6. documentar a origem e a decisão.
